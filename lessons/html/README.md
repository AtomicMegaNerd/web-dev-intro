# HTML and CSS Reference Information

## Running Sites with Live-Server

To load any sites in this repo live:

```bash
live-server --no-browser /folder/with/html
```

Do not point to index.html point to the folder so all resources in the folder (inclduing CSS and
Javascript) get loaded.
