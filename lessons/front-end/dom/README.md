# The DOM

The Document Object Model.

## CSS Styles

In Javascript styles use _camelCase_.

```js
redSquare.style.backgroundColor = "limegreen";
```

In CSS styles use _kebab-case_:

```css
.red-square {
  background-color: limegreen;
}
```
