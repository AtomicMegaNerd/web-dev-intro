# JavaScript Object Notation (JSON)

This is already pretty familiar...

```json
{
  "name": "Bill",
  "age": 32,
  "gender": "male",
  "location": {
    "city": "Calgary",
    "province": "Alberta"
  }
}
```

99.99999% of all JSON is valid Javascript. Apparently it is non-trivial to write JSON that isn't but
it is possible.

## Types

- strings (always double-quotes)
- objects
- numbers
- booleans
- arrays
